### The selected SNPs associated with the non-genetic factors
Folder [`./mr/SNPs`](./mr/SNPs/) contains the SNPs associated with the non-genetic factors. 

### The Mendian randomization (MR) results for the non-genetic factors
+ Coronary artery disease:  
The `exposure` columns of [CAD-causation_phenotypes_ivw.csv](./mr/CAD/CAD-causation_phenotypes_ivw.csv) include the ID of the GWAS associated with that non-genetic factor. 
For example, `Arm fat mass (left)  || id:ukb-b-8338` indicates that the GWAS ID for the factor `Arm fat mass (left)` is `ukb-b-8338`. Retrieve this ID from [openGWAS](https://gwas.mrcieu.ac.uk/) database to get the information of GWAS summary statistics for `Arm fat mass (left)`.

## Conda Environment
The file of conda environment installation is provided.
1. Modify the prefix path in the final line of `environment.yaml` file according to user's conda path;
2. Run this command to install all python dependency for MIDRP
``` bash
conda env create -f environment.yml
```  
Activate conda env
``` bash
conda activate MIDRP
```

## Descriptions for input files and settings:
### user input params
- `PRS_score_path = f'./PRS/LDPred2/{Disease}':` the path of the PRS score file. The PRS score file can be generated by LDpred2 or other PRS methods.
- `non_genetic_data_path = f'./non_genetic_data/{Disease}/model_needed_data':` the path of the non-genetic data file (such as the lifestyles and physical measurements).
- `label_path = f'./non_genetic_data/{Disease}/model_needed_data':` the path of the disease label file. The disease label file is a binary file, where 1 indicates the disease case and 0 indicates the control.
- `med_path = f'./Med-Transformer/extracted_info/{Disease}':` the path of the extracted information file from the Med-Transformer.
- `PRS_Method = 'LDpred2'`
- `save_dir = f'./MIDRP_results_MRfactors_med_{PRS_Method}'`


### Example output (path: ./MIDRP_results_MRfactors_med_LDPred2):
+ CAD_LDpred2_auroc.txt: the AUROC on the test set
+ CAD_LDpred2_best_hyper.txt: the indexes of best alpha and beta 
+ CAD_LDpred2_y_pred.txt: the precited score on the test set
+ CAD_LDpred2_y_test.txt: the true disease label on the test set
